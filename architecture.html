轻天璇 Studio · 系统架构

四层架构，两条总线：控制面编排，数据面执行，模型层统一出网

创作者只接触 API 网关，业务服务完成鉴权、资产与计费；NeoFlow 拆 DAG、管调度，任务由 NeoTask 拉取执行，驱动六环推进。PenFix 挂在视频、音频与初剪之后做三道质检，不合格按根因回退；六环之间只交换 JSON，不互相调用。

LIFECYCLE

一次整集请求，如何穿过四层

点任一环节，会回到上方架构板并高亮对应组件。这里只描述职责边界，具体技术实现可替换。

DATA CONTRACTS

六环之间只交换契约，不互相调用

契约是唯一的耦合点：上游只承诺字段结构，不暴露内部实现。落地时用 JSON Schema 固化版本，字段演进走兼容升级，重跑与回退都从契约快照恢复。

环节 输入 输出 契约要点 自检 / 人审
PenPlot 创意简述 · 人设 / 世界观 SCRIPT · JSON 故事线、幕结构、角色与场景清单、情绪走向 结构模板自检；创作取舍人审
PenShot SCRIPT · JSON FRAGMENT · JSON 镜头号、画面描述、运镜、台词、时长 一致性自检；模糊镜头人审
PenGen FRAGMENT · JSON MEDIA · MP4 shot 编号、模型、分辨率、帧率、时长 画面一致性 + 技术指标自检
PenDub 台词 + 音色 / BGM 参数 MEDIA · WAV shot 编号、音色、音效、BGM、音画对齐 音画同步 + 音频指标自检
PenClip MEDIA · MP4 / WAV TIMELINE · JSON 轨道、镜头顺序、转场、时长、混音 节奏与时长检查；终审人审
PenFix 任一环节产物 PASS / FAIL + 根因 门位、指标、根因、建议回退点 判定写回事件；回退由 NeoFlow 执行

QC & ROLLBACK

三道质检门，按根因回退

质检挂在 Gen、Dub 与 Clip 之后。回退点由根因决定：改提示词能解决的，不重剪；重剪能解决的，不重生成。

GATE 01 · 画面门

PenGen 之后

逐 shot 检查画面一致性、人物与场景连续性，以及分辨率、帧率等技术指标。

不通过回 PenShot 改分镜与提示词，重生成对应 shot。

GATE 02 · 音画门

PenDub 之后

检查音画同步、音量与音频指标，确认每句台词落在该落的镜头上。

不通过回 PenShot 调整台词与节奏，重配对应片段。

GATE 03 · 成片门

PenClip 之后

检查叙事节奏、转场、时长与内容合规，给出初剪终审结论。

不通过剪辑 / 混音问题回 PenClip 重剪；素材缺陷按镜头回 Gen / Dub。

升级策略：同一问题重试两次仍不过，升级为按镜头重生成；重生成仍不过则转人工介入，判定记录与上下文一并保留，避免下一轮从零排查。

OPERABILITY

长任务链路的可运维性

整集生成动辄数十个任务，最怕跑到一半全部丢失。状态、重试、配额与人审断点都要在架构里预留位置。

01

断点续跑

DAG 状态与产物快照落 Redis，任务中断后从最近完成的节点继续，不必整集重跑。

02

失败重试

单节点按退避重试；模型超时或限流由 NeoFlow 换模型重跑，不把错误直接抛给上游。

03

优先级与配额

NeoTask 任务池支持优先级插队与租户配额，交互式请求不被批量长任务挤占。

04

人工在环

剧本、分镜与终审保留人工改写断点，人工结论回写契约，下游按新契约继续。

05

资产复用

角色、场景、道具与模型沉淀为资产库，跨镜头、跨集引用，减少重复生成与风格漂移。

06

指标与留痕

任务事件、进度与失败原因统一上报，形成可用率、耗时与单集成本指标。

EXTENSIBILITY

变化收敛在三个位置

分层与总线把变化关进少数接口里：新增能力不需要改上下游，也不需要重写调度。

扩展点 · 新环节

按契约实现 Worker

注册进 DAG 就能插到任意位置；上下游只认 JSON 契约，不感知环节内部实现。

扩展点 · 新模型

在网关注册供应商

路由、限流与降级顺序统一配置，节点代码不动；换模型不改业务逻辑。

扩展点 · 新租户 / 计费

业务层隔离，调度层共用

资产与配额按租户隔离，限流与计量放在网关；任务池与执行层保持共享。

INVARIANTS

四条不变量：实现可换，边界不换

  • 控制面不跑推理NeoFlow 把整集请求拆成 DAG，任务进 NeoTask 任务池；NeoTask 管优先级与重试，六环只订阅状态。
  • 状态与记忆分离Redis 存热状态、队列与事件；向量库存世界观与长文本记忆，供 PenPlot、PenShot 检索。
  • 数据面只传契约剧本与分镜先自检自修、必要时人工修正，再交给下游；Gen/Dub 不合格回分镜改提示词，Clip 终审按根因回 PenClip 重剪或回 Gen/Dub 重生成。
  • 模型统一出网AI Gateway 收敛鉴权、计费、限流与路由；调用失败由 NeoFlow 换模型重试。
